# LoanTracker

NiceGUI app to track loans, add extra payments, and compare baseline vs what-if payoff timelines.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -e .
python main.py
```

## Notes
- Data is stored locally at `~/.loantracker/loantracker.db`.
- Use the overlay controls to adjust what-if extra monthly payment and compare with baseline.
